> 原则：**HTML 和 CSS 不算考点，可以复制；所有 JS 逻辑必须自己写。**
> 写不出来不是失败，是精准定位漏洞 —— 记下来告诉我。

## 一、开工前 10 分钟：准备

1. 复制 `阶段0产物/index.html` → 另存为 `index-重写.html`
2. 打开 `index-重写.html`，**把整个 `<script>` 里的代码全删掉**（保留 HTML 结构和 CSS）
3. 浏览器打开，此时应该看到：上方表单（学号/姓名/年龄/性别/家乡 + 录入按钮）、下方空表格（6 列表头）

> 这一步做完，你面对的是一个"有骨架没肌肉"的页面 —— 正好。

## 二、五步施工（每步做完必须验证，再进下一步）

### 第 1 步：渲染（约 30 分钟）

**目标**：页面表格里出现 3 条假数据。

**先想清楚三件事**：
1. 数据存在哪？→ 先写一个**数组**，里面放 3 个对象（每个对象要有 stuId、id、name、age、gender、hometown）
2. 数组怎么变成表格行？→ 你学过 `map` + `join`（133/134 集）
3. 每一行长什么样？→ 6 个 `<td>` + 一个删除链接

**验收**：刷新页面，表格显示 3 行，控制台无红字。

**卡住就问自己**：数组定义好了吗？map 里 return 的是不是字符串？拼好的串塞到哪个元素里了？

---

### 第 2 步：本地存储（约 20 分钟）

**目标**：第 1 步的假数据存进浏览器，刷新不丢。

**先想清楚三件事**：
1. 什么时候存？→ 数据发生变化之后
2. 什么时候读？→ 页面一打开就读（脚本最前面）
3. 有什么坑？→ **第一次打开时 `getItem` 返回 `null`**，直接 `JSON.parse` 后拿到的不是数组

**验收**：F12 → Application → Local Storage，能看到一个键（建议叫 `stuList`），值是 JSON 字符串；刷新页面数据还在。

**卡住就问自己**：`JSON.stringify` / `JSON.parse` 哪个是存哪个是取？`null` 怎么兜底（`|| []`）？

---

### 第 3 步：新增（约 30 分钟）

**目标**：填表单点「录入」，表格多一行，表单自动清空。

**先想清楚四件事**：
1. 你的表单是 `<form>` → 点按钮时浏览器**默认会刷新页面**，怎么拦住？
2. 四个输入框的值怎么取？**年龄是字符串，要转数字**（不然第 5 步统计会出错）
3. 新学生的唯一 id 从哪来？→ 你学过 `Date.now()`
4. 数据 push 进数组后，页面会自己变吗？→ **不会，必须手动重画**；画完还要存盘、清空表单

**验收**：录入 1 条 → 表格多一行 → 刷新页面数据还在 → 表单已清空。

**卡住就问自己**：`submit` 还是 `click`？`e.preventDefault()` 写了吗？`this.reset()` 在哪个函数里有效？

---

### 第 4 步：删除（约 25 分钟）

**目标**：点「删除」，那一行消失，刷新后也不回来。

**先想清楚三件事**：
1. 事件绑在哪？→ 表格是动态生成的，所以要绑在 **tbody** 上（事件委托）
2. 怎么知道删哪一条？→ 渲染时给删除链接加 `data-id`，点击时从 `dataset.id` 拿
3. 删除后要做什么？→ 改数组（`splice`）→ 重画 → 存盘

**验收**：删中间那行，只有它消失；刷新后仍不在。

**卡住就问自己**：`e.target` 是哪个元素？`tagName` 判断了吗？`dataset.id` 拿到的是字符串，`splice` 能用吗？

---

### 第 5 步：统计（约 25 分钟）

**目标**：表格下方显示「共 X 人，平均年龄 Y 岁」。

**先想清楚三件事**：
1. HTML 里有统计条吗？→ 没有就自己加一行（`<p>` + 两个 `<span>`）
2. 更新逻辑写在哪？→ **render 函数的最后**（这样增删都会自动跟着变）
3. 平均年龄怎么算？→ 所有 age 求和 ÷ 人数；**0 人时要特判，否则显示 NaN**

**验收**：录 3 条显示 3；全部删光显示 0 人、平均 0（不是 NaN）。

**卡住就问自己**：求和用什么循环？`arr.length ? ... : 0` 这个三元你写过吗？

## 三、卡住时的自查顺序（照这个顺序查，别乱猜）
