## C. 机器核验出的确凿错误（已回读，非推测）

### ① `JS/第二十一天/4-3练习.html:10-13` —— SyntaxError，跑不起来

```js
function setMoney(yu, chi, huo) {        // 10 行：声明了 3 个形参
  let yu = +prompt('请输入银行卡余额')    // 11 行：又用 let 声明一次 yu
  let chi = +prompt('请输入当月食宿消费金额')
  let huo = +prompt('请输入当月生活消费金额')
```

**错误**：形参 `yu/chi/huo` 与函数体内 `let yu/chi/huo` 重名 → `SyntaxError: Identifier 'yu' has already been declared`。

**这也说明你 21 号改的那一版不是修好了，是改错了** —— 形参声明了却完全没用到，数据仍从函数内部 prompt 拿。

**正确结构**：prompt 在**函数外**取值 → 传进函数 → 函数只负责算。

### ② `JS/第二十二天/2-随机点名案例.html` —— 语义反了

你注释写「得到 0~6 的随机索引」，代码是 `Math.floor(Math.random() * arr.length)`，数组长度 7 → 实际范围 **0~6 共 7 个数，是对的**；但注释写「这个随机数 0 ~ 6」没问题、第 1 行注释写"随机数1 0~6"多打了一个 1。

**真正的问题在下一篇**：`arr.splice(random, 1)` 写对了（删掉被点到的人），但**没有判断数组被删空的情况**。点名点 7 次后 `arr.length = 0`，`Math.floor(Math.random() * 0)` 恒为 0，`arr[0]` 是 `undefined`，页面会输出 "undefined"。这是你的代码里**唯一一条逻辑漏洞**。

### ③ `JS/第二十二天/3-2猜数字游戏-固定次数.html` —— 循环次数与题干不符

代码是 `for (let i = 1; i <= 3; i++)`，**只给 3 次机会**；题干第 12 题要求 **5 次**。逻辑本身正确（flag 开关 + break 都写对了），只是次数抄错。
